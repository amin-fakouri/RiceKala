## About RiceKala

**RiceKala** is a multi-vendor marketplace platform designed specifically for the rice market.

Unlike a traditional online rice shop, RiceKala is built around a **marketplace model**, where multiple sellers can offer their rice products through the platform. Customers can explore available products, compare different sellers and make better purchasing decisions.

The project was built to explore the architecture and development of a real-world marketplace using the Laravel ecosystem.

### Key Goals

* 🛒 Multi-vendor marketplace architecture
* 🏪 Support for multiple rice sellers
* 🍚 Rice product listing and management
* 🔎 Easier product and seller comparison
* 👤 Customer and seller workflows
* 📊 Dashboard-based management
* ⚡ Dynamic interfaces with Livewire

## Installation

Clone the repository:

```bash
git clone https://github.com/amin-fakouri/RiceKala.git
cd RiceKala
```

Install PHP dependencies:

```bash
composer install
```

Create the environment file:

```bash
cp .env.example .env
```

Generate the application key:

```bash
php artisan key:generate
```

Configure your database in `.env`, then run:

```bash
php artisan migrate
```

Start the development server:

```bash
php artisan serve
```
